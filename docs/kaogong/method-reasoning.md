# 判断推理：方法与思路

> 四大题型：图形推理、定义判断、类比推理、逻辑判断。**最像数学、最能速成**的模块——方法对，两周见效。

## 一、题型地图与性价比

| 题型 | 提分特点 | 核心方法 | 时间预算 |
|---|---|---|---|
| 图形推理 | 靠刷题养敏感度 | 规律排查顺序 | 40 秒/题 |
| 定义判断 | 纯细心，送分题 | 拆要件逐项比对 | 50 秒/题 |
| 类比推理 | 快，容易粗心 | 造句法 + 二级辨析 | 30 秒/题 |
| 逻辑判断 | 纯方法，可速成 | 翻译公式 + 论证结构 | 90 秒/题 |

## 二、图形推理

**规律排查顺序**（没思路就按这个清单过）：

```text
① 对称：轴对称 / 中心对称，对称轴的方向与数量
② 一笔画：奇点数为 0 或 2 才能一笔画
③ 封闭开放、曲直
④ 位置：平移（方向 + 步长）、旋转（角度）、翻转
⑤ 叠加：直接叠加、去同存异、去异存同、黑白运算
⑥ 数量：点、线、角、面、素（元素种类与个数）
```

空间重构（折纸盒）两招：

```text
相对面排除：相对面不可能同时出现在视图中
时针法：确定相邻三个面的相对方向，选项方向不对即排除
```

经验：一道图推超过 40 秒没思路直接跳过——图推是"识别大于推理"，见过的规律才会再见面。

## 三、定义判断

```text
拆要件：主体、客体、目的、方式、结果、限定条件
逐项比对：一个要件不符，立即排除
```

三个细节：

- 多定义题（一段给好几个定义）：**只读被问的那个**
- "不属于"反向题：圈出"不属于"三个字，防止惯性选正向
- 定义又长又难：先看问法和选项，带着关键词回头读定义

## 四、类比推理

两步走：**先造句子，再二级辨析**。

常见关系清单：

```text
语义：全同、近义、反义
并列：矛盾关系（生 vs 死） / 反对关系（红 vs 绿）
包含：种属（苹果 vs 水果） / 组成（轮胎 vs 汽车）
对应：功能、材料、因果、职业与工具、产地
语法：主谓、动宾、偏正（形容词修饰名词）
```

二级辨析（一级分不出来时）：

```text
词性（名词 vs 动词）、感情色彩（结果 vs 后果）
词语结构、具体与抽象
```

经验：先横向比（题干两词的关系），后纵向比（选项之间的差异）；造的句子越简单越通用越好。

## 五、逻辑判断

### 翻译推理（必背公式）

```text
如果 A 那么 B    →  A 推 B
只有 A 才 B      →  B 推 A
A 且 B           →  同真才真
A 或 B           →  一真则真；否定一个推出另一个
并非（A 且 B）   →  非A 或 非B
并非（A 或 B）   →  非A 且 非B
逆否等价：A 推 B  等价于  非B 推 非A（肯前必肯后，否后必否前）
```

### 加强削弱

```text
第一步：找论点（结论）和论据
第二步：削弱力度排序
  切断论证（另有他因、因果倒置）> 否定论据 > 质疑论点
第三步：加强 = 搭桥（论据与论点之间补联系）> 补充新论据
```

### 真假话问题

```text
找矛盾对（必一真一假）→ 绕开矛盾，从其余条件入手 → 回头解矛盾
```

### 分析推理

信息量大：列表法（重复出现的信息优先用）；选项具体：代入排除。

## 六、学习方法

1. **逻辑判断先学翻译公式**，它是整个判断推理的地基，两周可成
2. 图形推理每天 10 题养手感，见过的规律都会再见面
3. 类比推理练"快而准"，错题多为二级辨析疏忽
4. 判断推理是行测/职测里方法论最密集的模块，刷题前先把本页公式过熟
