# 资料分析公式速查

> 本页只放公式和秒杀结论，推导过程与完整例题见[《资料分析》笔记](/kaogong/data-analysis)。
>
> 术语对照：**现数 = 现期量**，**基数 = 基期量**，r = 增长率。

## 一、核心关系（一切公式的地基）

```text
增长量 = 现数 - 基数                （绝对关系，减法，带单位）
增长率 = (现数 - 基数) / 基数        （相对关系，除法，无单位）
倍数   = 现数 / 基数
```

黄金恒等式：**增长率 + 1 = 倍数**。

## 二、四大核心量互推

| 已知 | 求 | 公式 |
|---|---|---|
| 基期量、r | 现期量 | 现期量 = 基期量 × (1+r) |
| 现期量、r | 基期量 | 基期量 = 现期量 ÷ (1+r) |
| 现期量、r | 增长量 | 增长量 = 现期量 × r/(1+r) |
| 现期量、基期量 | r | r = (现-基) ÷ 基 |

## 三、增长率全家桶

| 公式 | 内容 |
|---|---|
| 间隔增长率 | r隔 = r1 + r2 + r1×r2 |
| 连续增长率 | 总增长率 = (1+r1) × (1+r2) × ... × (1+rn) - 1 |
| 年均增长率 | r均 = (现期量/基期量)^(1/n) - 1，n = 年份差（不是年份个数） |
| 乘积增长率 | r总 = rA + rB + rA×rB（总量 = A × B 时） |

年均增长率粗估：r均 ≈ 总增长率 / n（结果偏大，是上界，选答案往小档修正）。

## 四、比重

```text
比重 = 部分 / 整体
部分 = 整体 × 比重
整体 = 部分 / 比重
基期比重 = 现期比重 × (1+整体r) / (1+部分r)
```

升降判断（只比增长率，不用算）：部分r 大于 整体r → 比重上升；部分r 小于 整体r → 比重下降。

## 五、平均数

```text
平均数 = 总量 / 份数
平均数增长率 = (总量r - 份数r) / (1 + 份数r)
```

## 六、比值混合（加权平均）

```text
整体比值 = (A×a + B×b) / (A + B)      （A、B 是部分量，a、b 是部分比值）
十字交叉反求比例：A / B = (b - r) / (r - a)
```

秒杀：整体比值必介于 a、b 之间，且**偏向量大的那部分**。三大应用：混合增长率、混合比重、混合平均数。

## 七、拉动增长与增长贡献率

```text
拉动增长率 = 部分增长量 / 整体基期量
增长贡献率 = 部分增长量 / 整体增长量
```

区别：分母一个是基期总量、一个是总增长量。

## 八、速算技巧

**特殊分数（背到肌肉记忆）**：

| 分数 | 百分数 | 分数 | 百分数 |
|---|---|---|---|
| 1/2 | 50% | 1/8 | 12.5% |
| 1/3 | 33.3% | 1/9 | 11.1% |
| 1/4 | 25% | 1/11 | 9.1% |
| 1/5 | 20% | 1/12 | 8.3% |
| 1/6 | 16.7% | 1/13 | 7.7% |
| 1/7 | 14.3% | 1/15 | 6.7% |

**三个套路**：

```text
增长量：把 r/(1+r) 换成特殊分数
        例：240 × 20%/120% = 240 × 1/6 = 40
基期量：把 1/(1+r) 换成特殊分数
        例：325 ÷ (1+1/7) = 325 × 7/8 ≈ 284
截位直除：选项首位各不相同 → 除数截前 2 位；首位相同次位不同 → 截前 3 位
```
