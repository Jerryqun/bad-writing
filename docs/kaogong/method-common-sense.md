# 常识判断：方法与思路

> 范围无边，**策略大于知识**：抓高频、用碎片、重时政，目标 60~70% 正确率，不追求全覆盖。

## 一、模块地图与优先级

| 模块 | 高频考点 | 优先级 |
|---|---|---|
| 时事政治 | 考前 6 个月大政方针、重要会议、周年纪念 | 最高（事业编职测占比大） |
| 法律 | 宪法、民法典、行政法、新颁布新修订的法律 | 高（新法必考） |
| 历史人文 | 朝代脉络、文学常识、传统文化（节气、节日） | 中 |
| 地理科技 | 自然地理、生活物理化、前沿科技成就 | 中 |
| 政治经济 | 马哲基本原理、宏观经济调控 | 中 |

## 二、解题思路

排除为主，四条蒙题直觉：

```text
① 绝对化表述（都、所有、一定、任何）慎选，留有余地的往往对
② 与国家大政方针方向一致的表述往往对
③ 法律题盯"应当 / 可以"、数字与范围的偷换
④ 时政题凭印象选"见过的"，纯生僻的统一猜同一个选项
```

多选题（部分事业编考试）策略：宁缺毋滥，确定的再选。

## 三、学习方法

1. **碎片时间刷 APP**：每天通勤 30~50 题，不占整块复习时间
2. **抓"高频 + 新增"**：考前半年的时政整理、新法条，比通读教材值钱得多
3. 错题直接背结论，不做深度分析（常识不需要推理过程）
4. 周期性复盘：一个月内见过的考点再看一遍，防遗忘

## 四、考场策略

常识单题控制在 30 秒内，会就会、不会就猜，把时间留给言语和资料分析——**常识是唯一不值得恋战的模块**。
