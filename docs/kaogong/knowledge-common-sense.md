# 常识知识积累

> 常识判断的知识点积累页：只记"考过的、易混的"，按模块滚动扩充，配合碎片刷题反复见面。

## 一、法律

### 1.1 民事主体三分类

《民法典》把民事主体分为三类，选择题常考"某个人 / 组织属于哪一类"：

```text
自然人、法人、非法人组织
```

### 1.2 非法人组织

> 《民法典》第一百零二条：非法人组织是不具有法人资格，但是能够依法以自己的名义从事民事活动的组织。

法定类型（条文列举三类 + "等"字兜底）：

| 类型 | 说明 |
|---|---|
| 个人独资企业 | 一个自然人出资，财产为投资人个人所有 |
| 合伙企业 | 普通合伙（含特殊的普通合伙）、有限合伙 |
| 不具有法人资格的专业服务机构 | 如合伙制的律所、会计师事务所 |

考点拆解：

```text
① "不具有法人资格" ≠ "没有民事主体资格"——它能依法以自己的名义从事民事活动
② 与法人的核心区别在责任承担：
   非法人组织的财产不足以清偿债务的，出资人或者设立人承担无限责任（第一百零四条）
   法人以自己的全部财产独立担责，股东以认缴出资额为限
```

关联易混点（"有没有法人资格"高频判断）：

```text
分公司：法人依法设立的分支机构 → 不具有法人资格，责任由总公司承担
子公司：具有法人资格，独立承担民事责任
个体工商户：自然人从事经营的形式，归入自然人，不是"组织"
```

做题手感：题干问"下列属于非法人组织的是"，先排除法人干扰项——"××有限公司""××股份有限公司"是营利法人；再排除自然人形态（个体工商户）；剩下的按三类列举对号入座。题干若把"不具有法人资格"偷换成"不具有民事主体资格"，直接判错。

### 1.3 无民事行为能力人

> 《民法典》第一百四十四条：无民事行为能力人实施的民事法律行为无效。

民事行为能力三分与行为效力对照（总则编高频考区）：

| 主体 | 判断标准 | 实施民事法律行为的效力 |
|---|---|---|
| 完全民事行为能力人 | 18 周岁以上成年人；16 周岁以上以自己劳动收入为主要生活来源的未成年人视为完全 | 有效 |
| 限制民事行为能力人 | 8 周岁以上的未成年人；不能完全辨认自己行为的成年人 | 纯获利益的、与年龄智力精神状况相适应的 → 有效；其余效力待定，经法定代理人同意或追认后有效 |
| 无民事行为能力人 | 不满 8 周岁的未成年人；不能辨认自己行为的成年人（8 周岁以上不能辨认的同样适用） | 一律无效 |

考点拆解：

```text
① 无民事行为能力人实施的民事法律行为一律无效，考试按法条字面掌握——
   哪怕纯获利益（接受赠与、收红包）也无效，这是与限制民事行为能力人的最大区别
② 限制民事行为能力人的"其余行为"效力待定：经相对人催告，法定代理人 30 日内
   未作表示的，视为拒绝追认
③ 年龄分界线：8 周岁（限制）、18 周岁（完全）；16 周岁 + 劳动收入为主要生活来源 = 视为完全
```

做题手感：题干出现"7 岁儿童接受赠与"这类纯获利益情境，直觉容易选"有效"，但无民事行为能力人一律无效——"纯获利益有效"是限制民事行为能力人的规则；反过来"17 岁已工作自己养活自己"签订的合同按完全民事行为能力处理，不需要追认。

### 1.4 数份遗嘱的效力（继承编）

> 《民法典》第一千一百四十二条：遗嘱人可以撤回、变更自己所立的遗嘱。立遗嘱后，遗嘱人实施与遗嘱内容相反的民事法律行为的，视为对遗嘱相关内容的撤回。立有数份遗嘱，内容相抵触的，以最后的遗嘱为准。

考点拆解：

```text
① 民法典取消了原《继承法》"公证遗嘱效力优先"的规则——
   六种遗嘱形式效力平等，冲突时一律以最后订立的为准，不看形式
② 冲突范围有限：内容相抵触的部分按最后一份执行，不相抵触的部分各自有效
③ 最后一份若因形式要件欠缺而无效，则向前追溯，以之前最后一份合法有效的为准
④ 行为撤回：立遗嘱后又实施与遗嘱相反的行为（如把遗嘱处分的房产卖掉），
   视为对遗嘱相关内容的撤回，不需要另立遗嘱
```

遗嘱形式六种与要点速记：

| 形式 | 关键要件 |
|---|---|
| 自书遗嘱 | 亲笔书写 + 签名 + 注明年月日 |
| 代书遗嘱 | 两个以上见证人，一人代书，遗嘱人 / 代书人 / 其他见证人签名，注明年月日 |
| 打印遗嘱 | 两个以上见证人，遗嘱人和见证人在**每一页**签名，注明年月日 |
| 录音录像遗嘱 | 两个以上见证人，记录姓名或肖像及年月日 |
| 口头遗嘱 | 仅危急情况有效，两个以上见证人；危急消除后能另立其他形式的即失效 |
| 公证遗嘱 | 公证机构办理 |

```text
除自书、公证外，其余四种均需两个以上见证人
见证人排除：无 / 限制民事行为能力人、继承人、受遗赠人、与二者有利害关系的人
必留份：遗嘱应为缺乏劳动能力又没有生活来源的继承人保留必要份额
```

做题手感："甲乙先后立数份遗嘱"类题，干扰项常用旧法思维——"公证遗嘱优先于在后的自书遗嘱"，民法典时代直接判错；"口头遗嘱随时有效"同样错，看危急情况是否消除；注意问法是"以哪份为准"（找时间最后且形式合法的一份）还是"哪份无效"（查形式要件）。

## 二、经济

### 2.1 划转部分国有资本充实社保基金

> 国务院《划转部分国有资本充实社保基金实施方案》（2017 年印发）：划转比例统一为企业国有股权的 10%，将中央和地方国有及国有控股大中型企业、金融机构的部分国有股权划转充实社保基金，以弥补养老保险基金缺口。

三次分配层次对照（判断"这一举措属于哪种分配"的题眼）:

| 分配层次 | 主导力量 | 典型手段 |
|---|---|---|
| 初次分配 | 市场，按生产要素贡献分配 | 工资、利润、利息、地租 |
| 再分配 | 政府 | 税收、社会保障、转移支付 |
| 第三次分配 | 社会道德 / 公益力量 | 慈善捐赠、志愿服务 |

考点拆解：

```text
① 记数字：划转比例统一为企业国有股权的 10%
② 归属判断：社保基金是社会保障体系的组成部分，由政府主导 → 属于再分配，
   与初次分配（市场按要素分配）、第三次分配（慈善公益）划清界限
③ 政策目的：弥补因"视同缴费年限"政策形成的养老保险基金历史缺口，
   国有资本属于全民，收益充实社保 = 全民共享 → 促进收入分配公平
④ 逻辑链：国有资本全民所有 → 收益充实社保基金 → 社保是再分配手段 → 公平导向
```

做题手感：题干问"这一举措有利于"，正确项是"通过再分配机制促进收入分配公平"。干扰项的偷换手法有三类：把"再分配"换成"初次分配"（初次分配在生产领域由市场按要素完成，政府充实社保基金不在其中）；换成"第三次分配"（慈善捐赠才是第三次分配）；用"国有资本保值增值""提高企业生产效率"这类效率导向表述，干扰"公平"导向的问法。补一句总原则：初次分配和再分配都要处理好效率与公平的关系，再分配更加注重公平——政府主导的社保动作，优先往"公平"上靠。

### 2.2 集约型与粗放型经济增长方式

> 政治经济学通说：粗放型经济增长方式主要依靠增加生产要素的投入数量来推动增长——多投资、多上项目、扩大生产规模、增加产品数量；集约型经济增长方式主要依靠科技进步、改进机器设备、采用新技术新工艺、提高生产要素的使用效率来推动增长。

两种增长方式对比（题眼在"增长靠什么"）：

| 维度 | 粗放型 | 集约型 |
|---|---|---|
| 增长依靠 | 增加要素投入数量（资金、资源、劳动力） | 要素使用效率提高（科技进步、劳动者素质） |
| 典型做法 | 增加投资、扩大生产规模、增加产品数量 | 改进机器设备、采用新技术新工艺、技术改造 |
| 对应扩大再生产类型 | 外延式 | 内涵式 |
| 增长结果 | 高消耗、低效率，难以持续 | 低消耗、高效率，可持续 |

考点拆解：

```text
① 题眼抓"依靠什么增长"：科技进步 / 改进机器设备 / 新技术新工艺 / 提高效率 → 集约型；
   增加投资 / 扩大生产规模 / 增加产品数量 / 多上项目铺摊子 → 粗放型
② 对应扩大再生产的两种类型：粗放型 = 外延式（靠生产要素数量增加），
   集约型 = 内涵式（靠要素质量与效率改善），两个概念常绑着考
③ 政策线：1995 年党的十四届五中全会提出"两个具有全局意义的根本转变"——
   一是经济体制从传统计划经济体制向社会主义市场经济体制转变，
   二是经济增长方式从粗放型向集约型转变
④ 延伸串线："创新驱动"对应集约型，"要素驱动"对应粗放型；
   当前讲的"高质量发展""提高全要素生产率"与集约型增长一脉相承
```

做题手感：题干出现"企业增加产品数量""国家增加对企业的投资""扩大生产规模"这类动作，判粗放型，问"有利于经济持续、稳定、健康、快速增长"的选项直接排除；换成"科技进步""设备更新改造""新技术新工艺"则判集约型。两个高频偷换：一是把"集约型"偷换成"密集型"——劳动密集型 / 资本密集型是按要素密集度划分的产业类型，回答的是"产业结构是什么"，粗放 / 集约回答的是"增长靠什么"，二者不是一回事，别被诱导改判；二是问"保持较快发展速度的根本出路"时，正确项是转变增长方式、依靠科技进步，干扰项通常是"加大投资力度""扩大建设规模"——恰恰是粗放型本身。
