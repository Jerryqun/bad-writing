# 言语理解与表达：方法与思路

> 三大题型：逻辑填空、片段阅读、语句表达。核心能力是**抓语境 + 抓结构**，不是靠语感硬蒙。

## 一、题型地图与性价比

| 题型 | 大致占比 | 提分特点 | 核心方法 |
|---|---|---|---|
| 逻辑填空 | 约一半 | 慢（靠成语积累） | 语境呼应 + 词语辨析 |
| 中心理解 | 约三分之一 | 快（纯方法） | 结构分析找中心句 |
| 细节判断 | 少 | 中 | 回归原文逐项比对 |
| 排序 / 语句填空 | 少 | 中 | 捆绑技巧 + 位置定功能 |

时间预算：平均 40~50 秒一题，逻辑填空两空题可放宽到 70 秒。

## 二、逻辑填空

**思路：先读语境找呼应，再回头辨析选项——顺序不能反。**

语境提示四关系：

```text
解释关系：即、也就是说、冒号破折号    → 横线词义 = 解释内容
反对关系：但是、却、反而、殊不知      → 横线词义 = 反向
递进关系：甚至、更、以至于            → 横线词义程度更深
并列关系：顿号、"和"、分号            → 横线词义与并列项同向同级
```

词语辨析四角度：

```text
语义侧重（安静 vs 宁静）、感情色彩（果断 vs 武断）
程度轻重（批评 vs 批判）、搭配习惯（履行诺言 vs 执行命令）
```

经验：

- 高频成语优先背"每套卷都出现的那批"，生僻成语性价比低
- 两空题先拿最有把握的一空排除两个选项
- 拿不准时相信第一直觉——凭依据改答案常常改错

## 三、中心理解题（性价比最高的题型）

**结构分析法：找到中心句，答案就是它的同义替换。**

```text
转折结构：但是、然而、却          → 重点在转折之后
因果结构：因此、所以、可见        → 重点在结论
并列结构：此外、同时、分号        → 全面概括，不可偏废
总分 / 分总                      → "总"的部分是中心
提出问题 - 分析问题 - 解决问题    → 对策句常是重点
```

排除选项三刀：

- **偏离主题词**：主题词都没提的选项直接排除
- **概括不全**：只覆盖文段一部分的排除
- **过度引申**：文段没说的"对策、呼吁"慎选——主旨题选概括，意图题才选合理引申

## 四、细节判断

```text
逐项回归原文，专抓偷换：概念、时态、范围、逻辑、无中生有
绝对化词（都、所有、一定、必须、任何）重点核查
先看清问法："正确的是"还是"不正确的是"
```

## 五、语句排序与填空

排序三步：

```text
① 定首句：背景引入、下定义开头的是首句；指代词、关联词后件开头的不是
② 找捆绑：代词找指代对象、关联词配对、时间空间顺序
③ 验逻辑：整体通读一遍是否连贯
```

语句填空看位置定功能：

```text
段首：总起句（概括下文）
段中：承上启下（前后话题都沾）
段尾：总结句（收束全文）
```

## 六、学习方法与训练

1. 每天 15 题精做 + **错题归因**：词语不认识 / 语境没读出 / 结构没看清——三类原因对应三种补法
2. 成语积累按"语境 + 成语 + 辨析"三栏记，只背出现过的
3. 片段阅读先自己概括一句，再和正确选项比对，练概括能力
4. 事业编职测里言语占比高，是拉分主力，值得每天稳定投入
