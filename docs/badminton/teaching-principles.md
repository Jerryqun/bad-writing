# 教学训练原则与计划

## 我国羽毛球运动训练指导思想与技术风格

- **指导思想**：以我为主、以攻为主、以快为主
- **技术风格**：快、狠、准、活

## 教学训练原则

1. 自觉积极性原则
2. 合理安排运动负荷原则
3. 系统性原则
4. 直观性原则
5. 全面身体训练与专项体能训练相结合原则
6. 区别对待原则

## 注意事项

### 少儿训练安排

根据少儿身体、生理、心理、成长环境、智力发育等诸因素，科学合理地安排训练。启蒙阶段特别要注意相关素质敏感期的训练，多以游戏性方法手段进行教学，切勿“拔苗助长”；技术训练中把战术意识的培养贯穿始终。

### 习惯与规范培养

1. 从启蒙阶段就应注意特长的培养（包括技战术）
2. 从小养成重视准备活动与放松整理的良好习惯
3. 培养羽毛球运动中的文明规范

## 训练计划

### 定义

- **训练计划**：围绕训练目的开展的具体实施方案
- **青少年儿童训练计划**：应围绕运动员的长期发展指标和内容设定

### 计划类型

按时间跨度可分为：

- 多年训练计划
- 年度训练计划
- 阶段训练计划
- 月、周、日训练计划

## 青少年儿童身体能力发展模型（YPD）

### 年龄阶段划分

| 年龄阶段 | 生长率 | 发育阶段 |
| --- | --- | --- |
| 幼儿期 | 快速生长 | 青春前期 |
| 儿童期 | 稳定生长 | 青春前期 |
| 青春期 | 生长突增 | 青春期 / PHV |
| 青少年期 | 降速生长期 | 青春期后 |
| 成年 | 稳定 | 青春期后 |

> PHV = Peak Height Velocity（身高增长峰值期）。图例：颜色越深可训练性越高；浅蓝色为青春前期，深蓝色为青春期。

### 训练要素

模型涵盖的训练要素：基础动作（专项技能）、活动度、灵敏、速度、爆发力、力量、耐力。

### 结构化程度

训练内容随年龄由低到高递进：

非结构化 → 低结构化 → 中等结构化 → 高度结构化 → 非常高度结构化

## 训练计划的制定：启蒙阶段（6-8 岁）

1. 以积极有趣的游戏发展儿童的柔韧、灵敏、平衡、协调和速度
2. 发展初学者的时空感知能力及持拍的本体感觉能力
3. 掌握握拍法、发球法、击球法、基本步法和站位的基本姿势
4. 以比赛成绩为中心，培养竞争意识，发展兴趣
