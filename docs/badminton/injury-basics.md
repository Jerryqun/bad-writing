# 常见运动损伤

## 运动损伤的分类（按性质）

### 扭伤

关节的被动活动超过了关节的解剖学范围，导致关节周围的肌腱、韧带、关节囊、滑膜等受到牵拉而撕裂甚至断裂。**是运动中最常见的损伤**。

### 挫伤

体表直接受到外力作用，使皮下软组织、肌肉、韧带等受伤，皮肤无损或轻微损伤。

### 拉伤

肌肉、筋膜以及肌腱附近的软组织因受牵拉性的外力所致的组织部分撕裂或完全断裂。主要发生部位在**肌肉与肌腱连接处**，或在**肌腹**。

### 骨折与脱位

骨的连续性遭到破坏，或者构成关节的骨端对合面的正常解剖结构异常改变，发生移位。

## 踝关节扭伤

### 特征

- 踝外侧肿胀、淤血
- 行走困难、活动受限

### 防治

1. **急性期采用 PRICE 原则**：概括起来就是制动、休息、冰敷、加压、抬高，坚持到肿胀消除
   - P（Protection）：保护 / 制动
   - R（Rest）：休息
   - I（Ice）：冰敷
   - C（Compression）：加压包扎
   - E（Elevation）：抬高患肢
2. 小腿周围的肌肉松解
3. 踝关节的稳定性训练
4. 辅助治疗：超声波、冲击波

## 足底筋膜炎

### 特征

- 足跟或足底痛，踮脚足底痛
- 蹬地痛，长时间站立或运动后加重

### 防治

1. 小腿肌力训练
2. 足底筋膜放松
3. 足跟支撑性训练

## 肱骨内上髁炎

### 特征

- **肘关节内侧疼痛**：常感受肘关节内侧疼痛，可能反射至前臂，影响日常活动和生活质量
- **特定动作时疼痛加重**：提重物、拧毛巾、屈腕等动作时疼痛显著加剧
- **压痛明显**：肱骨内上髁处有明显压痛，轻触或按压该区域即可引发疼痛，是诊断的重要依据之一
