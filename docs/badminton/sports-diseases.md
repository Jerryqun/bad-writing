# 运动性疾病与处理

## 运动性晕厥

### 损伤机制

维持意识所需的脑血流量的临界值为 **30ml/100g**。当由于各种原因导致脑血流量低于这个临界值时，可引发晕厥。

### 征象

全身发软、头晕耳鸣、眼前发黑、面色苍白、手足发凉、脉搏细弱、血压降低等。

### 防治

- 平躺、足部抬高，增加脑血流量
- 注意通风和保暖
- 口服盐水和糖水
- 严重时需送往当地医院处理

### 常见类型

1. **重力性休克**：多见于中长跑运动员或爆发性训练中，如疾跑后突然坐着、蹲着或躺着都可能诱发。运动突然暂停时，之前由于肌肉收缩作用积聚在下肢的血液无法快速回流，导致脑部血流量不足，从而引起晕厥。
2. **胸内压和肺内压增加**：做大力量憋气时导致胸腔和肺内压增加，回心血量减少，引起晕厥。

4. **心源性晕厥**：心脏病如冠心病导致的心输出量不足，引起晕厥。
5. **中暑晕厥**：脱水导致血流量降低，引起晕厥。

## 肌肉痉挛

### 原因

1. **寒冷刺激**：皮肤直接暴露在寒冷环境下
2. **电解质丢失过多**：出汗量太大
3. **运动强度大**：肌肉放松不够

### 征象

肌肉剧烈收缩发硬、疼痛难忍，严重时甚至可能引起呼吸困难。

### 防治

1. 运动时注意强度，疲劳时注意休息和放松
2. 让患者仰卧，用热毛巾热敷和按摩痉挛部位
3. 换上保暖的衣物，注意通风
4. 口服盐水和糖水
5. 痉挛超过半小时没有缓解，送往当地医院处理

## 中暑

### 三种类型及征象

| 类型 | 征象 |
| --- | --- |
| 热射病 | 高热、无汗和昏迷，体温上升，脉搏细速，呼吸短促，严重可致心力衰竭或呼吸衰竭 |
| 热痉挛 | 水和电解质丢失导致的肌肉痉挛 |
| 热衰竭 | 头晕头痛、恶心呕吐、胸闷、面色苍白、冷汗淋漓、血压下降 |

### 热痉挛的防治

1. 将患者转移到阴凉通风的环境
2. 保持舒适的体位，一般是仰卧位
3. 保持呼吸道的通畅
4. 热痉挛患者口服凉盐水
5. 给予物理降温：在头部、腋窝、腹股沟放置冰袋，用凉水擦摩皮肤，加速血液循环
6. 运动或高温环境下及时补液
