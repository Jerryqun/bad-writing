# 羽毛球C级教练

> 羽毛球 C 级教练学习笔记，内容待补充。

## 教练员等级体系

- **C 级（初级）**：面向基层与大众教学，掌握基本技术与基础教学方法
- **B 级（中级）**：面向系统训练，掌握进阶战术与训练计划制定
- **A 级（高级）**：面向高水平竞技训练与队伍管理

## 考核方向

- **理论部分**：羽毛球竞赛规则、运动基础知识、教学组织方法
- **实践部分**：基本技术规范示范、教学组织与纠错能力

## 基本技术

### 握拍

- **正手握拍**：虎口对准拍柄窄面内侧的斜棱，掌心留空
- **反手握拍**：拇指顶在拍柄宽面上，其余四指自然握持

### 发球

- 正手发高远球
- 正手发网前球
- 反手发网前球

### 击球

- 高远球、平高球、吊球
- 杀球（重杀、点杀）
- 挑球、搓球、推球、勾球

### 步法

- 并步、交叉步、蹬跨步、蹬跳步
- 米字步法：场地六个方向的移动与回位
